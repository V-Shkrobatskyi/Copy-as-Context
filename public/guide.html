Copy as Context

Turn the open page into useful context.

Create a focused semantic export for an AI conversation without manually selecting, cleaning, or restructuring page content.

Everything is processed locally in your browser

A quick export in three steps

1

Open a page

Use the tab whose content you want to provide as context.

2

Choose the shape

Select a compression level and either Semantic Text or Markdown.

3

Take it with you

Copy directly into a prompt or save the result as a file.

Choose the right amount of context

Without

Keeps every captured semantic node. Use it when completeness matters more than length.

Detailed

Removes only empty presentation wrappers for readable, careful review.

Compact

Removes repeated accessibility noise while retaining meaningful controls. This is the default.

Maximum

Uses the strongest currently safe reduction. It currently matches Compact.

Export format

Choose Semantic Text for a concise outline or Markdown when you want formatting in your notes or AI chat.

Save preferences stores your compression, format, and privacy choice for the next time you open the popup.

Privacy is in your control

Redact sensitive data is on by default. It replaces detected credentials with [REDACTED] before the export reaches your clipboard or a saved file. Disable it only when you intentionally need original values.

If something does not work

This page cannot be captured

Chrome pages, the Web Store, and other extensions are restricted by the browser.

Capture is busy or fails

Close DevTools for the active tab and try again. Chrome only allows one debugger connection at a time.

Copy as Context works with the page’s accessibility structure, not by uploading the page to a service. View the project on GitHub.
