How to use filters

Use Duplicate to create an editable copy of any built-in filter. Turn the original off if you want your copy to replace it. Choose one Rule type for each custom row. To check the same terms in another place, add another row.

Matching rules contain literal names or prefixes, never regex. Use / (space, slash, space) between alternatives in every mode; commas and ordinary URL/path slashes are literal. Text hides literal alternatives. Text — single literal treats the entire cell as one phrase, preserving older rules. Case sensitive applies to the selected type.

Field labels hides the value and nested text of a matching field, keeping its label visible. Field labels — whole words requires word boundaries; Field labels uses substring matching. URL parameters hides values in ?name=value and &name=value; enter names without ?, &, =, # or line breaks.

Rule types and examples

Authorization: scheme names such as Bearer / Basic / CustomAuth, followed by whitespace and a credential of at least 8 characters. The scheme stays visible.

JWT: first-segment prefixes such as eyJ. Requires three dot-separated segments: at least 5 characters after the prefix in the first segment, and at least 5 in each remaining segment. Segments use letters, digits, underscores and hyphens.

GitHub tokens: prefixes such as ghp_ / github_pat_ / company_, followed by at least 20 letters, digits or underscores. AWS keys: prefixes such as AKIA / ASIA, followed by exactly 16 uppercase letters or digits (lowercase is also accepted when Case sensitive is off). OpenAI keys: prefixes such as sk- / sk-proj-, followed by at least 16 letters, digits, underscores or hyphens.

Assigned secrets: names such as api_key / token / private_key, followed by : or = and a value of at least 8 characters. Whitespace, &, quotes, commas and semicolons end the value. The label and separator stay visible.

Credential detectors require word boundaries, matching the built-in behavior. These are credential-shape checks, not cryptographic validation. Older rules with several modes become separate rows, preserving every check. Duplicate includes all built-in aliases and settings.
